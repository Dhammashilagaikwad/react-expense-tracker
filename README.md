# 💸 React Expense Tracker 

A simple and responsive **Expense Tracker web app** built with **React.js**, allowing users to manage their **income, expenses, and monthly budget** — with automatic balance calculations and visual summaries.

---

## 🚀 Features

### 🧩 1. Add Transactions
- Add **expenses** with category, date, and amount.  
- Add **income** with source and amount.  
- All data is saved in **localStorage** for persistence.  
- Validations handled using **React Hook Form**.

### 💰 2. Budget Management
- Set and edit a **monthly budget**.
- Budget is stored in `localStorage` by month (e.g., `2025-11`).

  - ✅ Total Income
